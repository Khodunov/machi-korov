# Храмы — четыре карточки

Готовы все четыре варианта. Встроенный image_gen; три новых сюжета сгенерированы короткими промптами на белом фоне, фон удалён локально. Первая карта с майбахом сохранена из предыдущей генерации с готовой прозрачностью.

Игровые параметры: стоимость 6, активация 6, «Возьмите по 2 монеты у каждого игрока / В свой ход.».
